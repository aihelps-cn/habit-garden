# 小小成长家

为孩子和家长设计的习惯养成网页，适配手机、平板和电脑。

## 功能

- 自定义习惯名称、emoji 图标、分类及每日奖励积分；同一习惯每天可打卡一次。
- 家长设置口令后可添加、编辑、删除习惯和奖励，以及带原因加减积分。
- 自定义实物或活动奖励；现金兑换支持填写整数金额，固定 1 积分 = 1 元。
- 兑换立即扣分，家长线下支付或兑现后确认；待兑现订单可取消并自动退分。
- 积分明细、兑换记录、连续打卡统计及本周打卡情况。
- JSON 备份导出与恢复。导出不包含家长口令，导入保留本地口令。

## 使用

首次使用在「家长管理」设置至少 4 位口令，然后配置孩子昵称、习惯和奖励。积分从 0 开始，没有预设虚假交易。每日完成后点击「打卡」，获得积分，前往「心愿商店」兑换。

数据仅保存在当前浏览器的 localStorage，不跨设备同步。家长口令用于家庭场景中的操作区分，并非服务端身份验证。现金支付由家长自行在线下完成，网页不发起转账。家长口令仅在当前页面会话有效，刷新后重新锁定。请定期导出备份并妥善保存口令。

## 本地开发与验证

要求 Node.js 22+。

```sh
npm run dev
npm test
```

预览地址：http://127.0.0.1:5173 。静态网站文件位于 dist/，无需构建或生产依赖。
